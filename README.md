# 🐾 Sistem Informasi Penitipan Hewan Njuah Vet

Sistem Informasi Penitipan Hewan Njuah Vet merupakan aplikasi berbasis web yang dikembangkan untuk membantu pengelolaan layanan penitipan hewan anjing dan kucing. Sistem ini menyediakan fasilitas bagi admin dalam mengelola operasional penitipan serta pelanggan dalam melakukan booking dan memantau kondisi hewan selama masa penitipan.

## ✨ Fitur Aplikasi

### 1. Dashboard
- Dashboard Super Admin dan Admin.
- Dashboard pelanggan.
- Informasi aktivitas dan statistik penitipan.
- Ringkasan data booking dan pendapatan.

### 2. Manajemen Penitipan
- Booking penitipan hewan.
- Pengelolaan data pelanggan.
- Pengelolaan data hewan.
- Pengelolaan kandang penitipan.
- Pengaturan ketersediaan kandang.
- Riwayat booking pelanggan.

### 3. Monitoring Hewan
- Monitoring hewan selama masa penitipan.
- Pencatatan status harian hewan.
- Pemantauan perkembangan kondisi hewan oleh pelanggan.

### 4. Pembayaran
- Pengelolaan pembayaran penitipan.
- Konfirmasi pembayaran.
- Pengelolaan metode pembayaran.
- Perpanjangan masa penitipan.
- Riwayat pembayaran.

### 5. Fitur Pendukung
- Laporan penitipan.
- Pengaturan sistem.
- Manajemen profil pengguna.
- Testimoni pelanggan.
- Notifikasi sistem.

## 🛠️ Teknologi

- PHP Native
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap

## ⚙️ Instalasi

1. Clone repository:

   ```bash
   git clone https://github.com/Abetnego2332009/sistem-informasi-penitipan-hewan.git
   ```

2. Pindahkan folder project ke direktori `www` pada Laragon atau `htdocs` pada XAMPP.

3. Buat database MySQL dengan nama:

   ```sql
   vet
   ```

4. Import file database `vet (2).sql` melalui phpMyAdmin.

5. Sesuaikan konfigurasi database pada file `koneksi.php`.

6. Jalankan aplikasi melalui browser sesuai direktori project.

## 🎯 Tujuan Pengembangan

Aplikasi ini dikembangkan untuk membantu proses administrasi penitipan hewan, mempermudah pengelolaan kandang dan booking, serta memberikan kemudahan bagi pelanggan dalam memantau status hewan selama dititipkan.
